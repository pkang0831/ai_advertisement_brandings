## 0. 내가 잘못한 것

- API/클라우드를 1순위로 제안한 것 → **폐기.** 다시 안 씀.
- Comfy **fp8** 14B를 Mac에 얹으려다 MPS `Float8` 미지원으로 깨진 뒤, 그냥 5B q8로 “됐다”고 한 것.
- face_lock 페인터리 입력으로 공포 룩 낸 것.

## 1. 현재 상태 (사실만)

| 있음 | 문제 |
|------|------|
| Wan **TI2V-5B Diffusers** (~32G) | 품질 천장 낮음. 샘플 비근접. |
| Comfy **I2V 14B fp8** + LightX2V | **MPS에서 fp8 불가** → 지금 포맷으로는 Mac Comfy 사용 불가. |
| 포토리얼 스틸 (anatomy_lock) | 입력으로 쓸 수 있음. |
| 5B로 뽑은 reels | 샘플급 **아님**. 후보 취급 금지. |

**갭:** 샘플에 쓰인 상용 I2V와 동급은 로컬에서도 어렵지만, **128GB면 Wan I2V 14B를 Mac-네이티브 경로로 돌리는 게 다음 정답**이다.  
지금 막힌 건 “14B 없음”이 아니라 “**Mac이 먹을 수 있는 14B 포맷이 없음**”.

## 2. 로컬-only 전략 (우선순위)

### P0 — 입력 게이트 (코드로 고정, 즉시)
- I2V 입력 = 포토리얼 화이트리스트만 (`anatomy_lock` 합격컷).
- `face_lock` / 페인터리 / 공포 텍스처 → **하드 리젝트**.
- 모션 = blink / breath / hair / micro weight only (샘플처럼 “살아 있는 거의 정지”).

### P1 — Mac이 도는 **I2V 14B** 가중치 확보 (Colab→Drive→rclone, 추론은 Mac)
Comfy fp8 대신 아래 **하나만** 받으면 됨 (로컬 추론용):

| 옵션 | 레포 / 형태 | 왜 |
|------|-------------|-----|
| **1순위** | `Wan-AI/Wan2.2-I2V-A14B-Diffusers` (또는 mlxgen이 받는 MLX 양자화본) | mlxgen / Diffusers·MLX 경로, Metal 친화 |
| **2순위** | Comfy용 **fp16/bf16** I2V 14B (fp8_scaled 아님) | Comfy Metal에서 로드 가능해야 함 |
| **보류** | 지금 있는 `*_fp8_scaled` | Mac MPS에서 **쓰지 말 것** (보관만) |

용량 큼(수십 GB). 받는 건 Colab→Drive→rclone (예전에 Wan 받을 때와 동일). **돌리는 곳은 이 Mac.**

### P2 — 로컬 런타임 고정
1. **mlxgen Wan I2V-A14B** (또는 동등 MLX 경로) @ 720p 세로, 81–121프레임  
2. 실패 시에만 Comfy + **비-fp8** 14B + LightX2V  
3. 후처리: RIFE/minterpolate → 30fps, 필요 시 2클립 스티치로 8–12초  

**5B는 프롬프트/구도 실험용.** 샘플 패리티 후보에 올리지 않음.

### P3 — 합격 게이트 (샘플 옆에 놓고)
- 첫인상: 공포/페인트/노이즈 없음  
- 얼굴·손 유지  
- 모션이 “죽은 사진”도, “얼굴 녹는 영상”도 아님  
- 해상도 ≥ 720p 세로  

탈락이면 배포 금지, 설정만 수정 후 재생성.
