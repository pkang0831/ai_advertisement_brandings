# Public Disclosure Draft Candidates

These are compliant draft bundles only. None is selected, default, approved, or authorized for publication. Only the user may choose a candidate. No validator or script in this package applies wording to an account or publishable release.

## `disclosure_c`

**Profile line:** Virtual character Rina • AI-generated scenes • Fictional Toronto swim diary

**Post line:** This post features Rina, a fictional virtual character, with AI-generated visuals. It does not depict a real person’s lived experience or live location.

## Decision boundary

- A candidate must retain explicit fictional/virtual-character and AI-generated disclosure.
- There is no human-identity or no-disclosure candidate.
- Editing, combining, or replacing a candidate creates new wording that requires a fresh user decision.
- Selection is recorded only by a deliberate update to `disclosure_decision.json`; this package performs no such update automatically.
